# structural_break_analyzer

Source of the `structural_break_analyzer` package as it was run for the paper. It holds
the ten detectors, the voting ensemble and the LLM attribution component that
`code/02_analysis.ipynb` calls.

Install it from the repository root:

    pip install -e package

The framework is described in

> Lukassen, F., Weisser, C., Schlee, M., Kumar, M., Thielmann, A., Saefken, B.,
> Silbersdorff, A., & Kneib, T. (2026). LLM-augmented changepoint detection: A framework
> for ensemble detection and automated explanation. arXiv.
> https://doi.org/10.48550/arXiv.2601.02957
